# 2026-08-01

## Product Hunt content script 日期溢出 bug 修复
- 问题：`src/app/producthunt.content/index.tsx` 的 `fetchProductUrls` 中 `postedBefore` 用 `day + 1` 直接拼字符串，查看某月最后一天（如 7月31日）时产生非法日期 `7月32日`。
- 根因：main.tsx 中 productHunt 链接指向"昨天"的榜单，今天 8月1号时昨天=7月31日，`31+1=32`。
- 修复：改用 `Date.UTC(year, month-1, day)` 作为起始日期，+24h 得结束日期，用 getUTC* 格式化，JS 自动处理跨月/跨年进位。postedAfter/postedBefore 都统一用这套逻辑。

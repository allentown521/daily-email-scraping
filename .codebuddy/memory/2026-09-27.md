# 2026-09-27

## smollaunch 列表脚本滚动逻辑改为渐进式
用户反馈原先「直接 `scrollTo(document.body.scrollHeight)`」不对。已改为对齐 `src/app/peerlist.content/index.tsx` 的人类式慢滚：
- 每次只滚 0.5~1 屏（`viewportHeight * (0.5 + Math.random() * 0.5)`），目标位置上限为 `scrollHeight - viewportHeight * 0.2`，`behavior: "smooth"`
- 每次滚动后随机等待 5~7s
- `maxScrollAttempts = 80`，`maxNoChangeCount = 5`；只有「高度未变 **且** 产品数未变」才累加 noChange
- 新增后台暂停：`document.hidden` 时面板显示 paused（⏸️ / #ff6b6b），前台恢复后继续且不消耗 pageCount（与 peerlist 一致）
- 面板状态文案 running 改为 "Scrolling"，并新增 Paused 分支
